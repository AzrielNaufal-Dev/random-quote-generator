# 🎲 Random Quote Generator

A clean, responsive, and minimalist web application that generates random inspirational quotes with a single click. Built with modern Vanilla JavaScript, CSS3, and Semantic HTML5.

![HTML5](https://img.shields.io/badge/HTML5-E34F26?style=for-the-badge&logo=html5&logoColor=white)
![CSS3](https://img.shields.io/badge/CSS3-1572B6?style=for-the-badge&logo=css3&logoColor=white)
![JavaScript](https://img.shields.io/badge/JavaScript-F7DF1E?style=for-the-badge&logo=javascript&logoColor=black)

---

## ✨ Features

- **Instant Quote Generation:** Displays a new quote and its author seamlessly upon clicking the button.
- **Initial Load Display:** Automatically populates a random quote when the web page finishes loading.
- **Responsive Layout:** Flexbox-based layout optimized for mobile, tablet, and desktop screens.
- **Clean UI & Transitions:** Smooth color palettes and hover animations for an enjoyable user experience.

---

## 🛠️ Tech Stack & Key Concepts

- **HTML5:** Structured semantic markup for accessibility.
- **CSS3:** Custom styling with Flexbox, CSS variables, and clean typography.
- **Vanilla JavaScript:** 
  - Array of Objects structure for quote storage.
  - Math logic (`Math.random()`, `Math.floor()`) for random indexing.
  - Dynamic DOM manipulation and Event Handling (`addEventListener`).

---

## 🚀 Getting Started

To run this project locally on your machine:

1. **Clone the repository:**
   ```bash
   git clone [https://github.com/AzrielNaufal-Dev/random-quote-generator.git](https://github.com/AzrielNaufal-Dev/random-quote-generator.git)

```

2. **Navigate to the project folder:**
```bash
cd random-quote-generator

```


3. **Open the app:**
Simply open `index.html` in your favorite web browser or use VS Code's **Live Server** extension.
